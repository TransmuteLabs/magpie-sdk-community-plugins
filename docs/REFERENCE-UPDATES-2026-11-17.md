## Границы проверки Command Code

Оба npm-архива проверены по опубликованным SHA-512 и SHA-1. Архив `1.89.1`
совпадает с исходным SHA-256 из source lock. Из 80 файлов изменились шесть:
CLI, версия пакета, changelog, два справочника и расширение VS Code.
`dist/index.mjs` совпадает. В 22 отдельно проверенных именованных функциях

совпадают. Это ограниченное статическое сравнение, а не доказательство
эквивалентности всего приложения.

её неполный результат сохранён. Повтор с рекомендованным увеличением лимита
завершил разбор, но граф связей остаётся частичным. CLI, его imports, VS Code

## Совместимость и выпуск

Свежий CLIProxyAPI `7df56074b252384d878ec4fca840552c6fb5236e`
дополнительно сопоставлен как референс общих политик. Его необязательная
continuity, конечный отказ обновления credentials и приоритет вложенного
Retry-After относятся к общим владельцам запросов, а не к шести копиям
провайдерных планировщиков. Само наличие нового hook в другом проекте
не разрешает повтор уже принятого или неопределённого платного запроса.
Из незавершённого рабочего merge CLIProxyAPI исходники не переносились.

Новые community-маркеры READ=3 относятся к обнаружению и установке
community-пакетов. У наших пакетов явные SDK-манифесты и собственный путь
установки; новый маркер не подменяет их контракт или разрешения.
Изменение типа ошибки Search1API и отсутствие выдуманного знаменателя
quota у WorkBuddy проверены как примеры существующих требований SDK:
сохранять статус, Retry-After и различие неизвестного значения и нуля.
Это проверка границ, а не свидетельство переноса этих провайдеров.

Минимальная ревизия API из манифеста, версия нашего пакета и версия
референса независимы. Публичный SDK выпускается с `VERSION` приложения;
wire API `1.12`, codec `0.5` и native ABI `1` остаются отдельными
идентификаторами совместимости.

Общие проверки Magpie и проверки отдельных пакетов также независимы.
Сравнение референсов не заменяет финальный прогон приложения, браузерные
проверки, проверку установки и живые испытания аккаунтов и harness.

## Завершённые проверки переносов

Command Code использует одну константу версии для native-запросов и
System One. Проверки фактически отправленных HTTP-заголовков воспроизвели
ошибку на прежнем коде. После исправления прошли двадцать повторов с
`-race`, весь пакет с `-race`, vet и проверка форматирования. Независимое
ревью закрыло найденное расхождение версий. Полный CLI вендора не запускался.

Zen выбирает DSH-псевдонимы по схеме инструмента, сохраняет обратное
преобразование ответов, историю, tool choice и защиту от коллизий.
Проверки воспроизвели ошибки на прежнем нормализаторе; новый прошёл
двадцать повторов с `-race`, затронутые проверки совместимости, vet
и форматирование. Независимое ревью проверило код и сохранённые результаты.
Отдельно исправлено соответствие JavaScript `trim`: U+FEFF удаляется,
U+0085 сохраняется. Это не проверка нового установленного OpenCode,
всего модуля или живого аккаунта.

Для OMP после обновления сведений об источниках также прошли существующие
проверки упаковки provenance и полного Source-манифеста. В этих тестах
компилятор заменён фиктивным исполнителем: они проверяют состав и
идентификаторы дистрибутива, а не новую нативную сборку или запуск клиента.

ZCode ограничивает Start шестью запросами по точному origin/proxy внутри
экземпляра модуля. Прежний предел в два аккаунта снят. Временная заполненность
не записывается как исчерпанная квота; слот освобождается при завершении или
закрытии Start-ответа, до чтения платного fallback. Выбор аккаунта, бюджет
ожидания и разрешение повтора остаются у хоста. Регрессии с двадцатью
повторами `-race`, весь пакет, vet и форматирование прошли. Независимое
ревью проверило также причинную мутацию освобождения слота. Ограничение
не является общим для разных поколений модуля, процессов или физических
IP; живые аккаунты и установленный клиент здесь не проверялись.

Devin ограничивает пятью минутами каждое ожидающее чтение HTTP-ответа.
Продолжающийся поток может длиться дольше; ожидание обработчика полученных
данных не расходует этот интервал. Оба пути, raw и decoded, используют
общий обработчик: отменяется только принадлежащий запросу HTTP-контекст,
сохраняются частичные данные, usage и неопределённый результат уже принятой
операции. Таймаут не даёт разрешения на повтор.

Ревью выявило дополнительную ошибку при отмене исходного caller во время
закрытия потока после таймаута. Четыре новые регрессии воспроизвели её на
прежнем коде; общий обработчик исправлен и сохраняет отдельно вид завершения
и его исходную причину. Отмена caller имеет приоритет при возврате, в том
числе при пользовательской причине deadline. Новые и прежние проверки
raw/decoded, двадцать повторов `-race`, vet и форматирование прошли;
независимое ревью закрыло обнаруженную ошибку. Первоначальные результаты и
отрицательное ревью сохранены отдельно от проверенного исправления.
