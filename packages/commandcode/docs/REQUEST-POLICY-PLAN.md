# API1.12 adoption plan, 2026-11-16 (SOL implementation)

Scope is commandcode and opencode package subtrees only. Astra owns review.
Preserve the dirty input tree and donor/version records. No host or root
metadata edits, commits, staging, branches, deletion, dependencies, credentials
or installed applications. The former layout-only restriction is superseded.

1. Freeze both complete input packages and inventory their bytes. Read public
   request-policy and effect-fence owners against the fixed usbox OBS source
   `/tmp/magpie-obs-policy-fix-20261115/candidate-01`. Do not substitute a moving
   host or private APIs.
2. Before runtime edits, add compiling SDK-wire regressions that demand original
   complete refusal facts and absence of accepted/output events on a documented
   whole-execution preflight rejection. Capture real assertion failures on old
   runtime code. Preserve controls for unknown/malformed/duplicate/truncated,
   accepted/output, transport interruption, native continuation/tool/cache and Jev.
3. Extract bounded original code/type/message and allowlisted HTTP timing before
   normalization. Separate envelope/no-effect proof from host classification.
   Return fresh RefusedExecution for entire pre-effect refusals. Use the shared
   named read-only callback only for idempotent discovery/account reads in the
   original execution; never add timers, account selection or auth replay.
4. Adopt capability/floors in every runtime variant that actually invokes it;
   preserve package release versions and historical evidence. Document excluded
   recovery flows with reasons rather than guessing vendor error semantics.
5. On regular guarded usbox only, pinned offline Go1.26.8 and isolated HOME/XDG:
   bounded affected unit/race/static/build checks, actual Front with installed
   native module for sibling/long-delay, terminal, fence, scope/budget/cancel
   cases. Freeze exact tested source hashes, receipts and any public SDK gaps.
   No broad host suite and no host source changes.

This is adoption, not a behavior-preserving cleanup. Existing helpers and
forwarding paths stay authoritative; parser duplication between independently
installable packages is preferable to a new runtime dependency.
