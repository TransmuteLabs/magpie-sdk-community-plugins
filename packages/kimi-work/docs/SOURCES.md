# Source provenance

This package is a Go port of `packages/kimi-work` version `0.1.17` from
`magpie-community/plugins`, pinned at commit
`e967ba4d946071c6c27a51cd5168b12ce832da5c` (identical package tree
`d57dc1b1e982639a8d086e27a2a2c3be55a9e879` on local `HEAD`
`964674642899f4827ed3d38e4a91fdc344e6448c`). The donor repository is not a
runtime dependency. `source-lock.json` records each donor file's SHA-256.
The donor MIT notice ships as `DONOR-LICENSE.txt`.

Note: `@magpie-community/agent-kimi-desktop` (`packages/kimi-desktop`, v0.1.7)
is a separate desktop-agent wiring package and is outside this provider port.
